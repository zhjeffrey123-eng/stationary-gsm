# 训练与固定验证标签

文件名为 `training_dataset_5000.h5`。它只含5000训练图案和100验证图案，不含测试标签。训练行是零基索引0:5000，验证行是5000:5100；`split=1`表示训练，`split=2`表示验证。

下载：[v3.2.0训练H5](https://github.com/zhjeffrey123-eng/stationary-gsm-awpl/releases/download/v3.2.0/training_dataset_5000.h5)。文件大小1,147,395,483字节，SHA-256为 `d31d313533f8c5c3e7b9947a8b2005f9f9afca821a3bd3469cafc5b1914a4d9a`。H5内部已经gzip压缩，直接保存到本目录即可。

| 字段 | dtype | 形状 | 含义 |
|---|---|---|---|
| masks | uint8 | 5100×8×8 | 1为金属像素 |
| active | bool | 5100×1152 | N24网格的有效电流行 |
| currents | complex64 | 5100×3×1152×18 | 5/7/9 GHz电流，非金属行补零 |
| responses | complex128 | 5100×3×18×18 | 相同物理解的响应矩阵 |
| split | float64 | 5100 | 固定训练/验证分区 |
| freq | float64 | 3 | GHz，固定[5,7,9] |

N=24、Q=192、M=1，周期0.020 m，入射角θ=0°、φ=30°，时间因子exp(-iωt)。`freq`单位为GHz；`currents`储存η₀J电流系数（η₀=376.730313668 Ω），端口为各Floquet阶依次排列的切向Ex/Ey电场系数，不能直接当作功率坐标。H5根属性同时给出这些单位和约定。

原600训练图案位于0:600，新增4400训练图案位于600:5000；原100验证图案保持其数组和顺序，迁移到5000:5100。新增图案均有32个金属像素，禁止周期2×2局部的仅对角接触。D4旋转/反射与64周期平移的规范轨道互异，并排除原900及独立1000测试图案的轨道；测试图案及标签均不随本数据文件提供。

完整标签中的 `generation_complete=True` 是训练入口的完成标志。训练时只使用选定的训练前缀或子集与固定100验证图案；不改变H5内容。`generate-labels`用这个文件中的实际几何重新计算新增物理标签，原600/100数组复制保持一致。
