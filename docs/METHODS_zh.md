# 物理模型、端口与数据约定

## 表面电流模型

周期 p=20 mm，零厚度 PEC 位于 z=0，两侧自由空间，时间因子为 exp(−iωt)。θ 从 z 轴计，φ 从 x 轴计。横向入射波矢 β=k₀sinθ(cosφ,sinφ)。正反配对采用 +β 与 −β，它们不是从两面照射的标记。

N 是每周期电流网格每边的单元数，Q 是 Green 谱整数截断，M 是 GSM 端口整数截断。每个 Floquet 阶 (m,n) 有两个切向 Ex/Ey 端口，每侧 P=2(2M+1)²，双面 GSM 为 2P×2P。未知电流先排列 N² 个 x 向屋顶基，再排列 N² 个 y 向屋顶基，每一块内 x 最快变化。

有效电流基的完整支撑必须位于金属内，周期边缘也检查另一侧金属邻居。电流系数是 η₀J，η₀=376.730313668 Ω。`physics.kernel` 用屋顶基的解析 Fourier 变换计算谱域 Galerkin 核。FFT 折叠只归并有限谱的整数别名，不改变 Q、积分或相位。没有加入人工损耗或对角正则化。

## GSM 提取

两组离散方程分别为 Z₊X₊=B₊、Z₋X₋=B₋，互易关系 Z₋=Z₊ᵀ。X 的行是有效金属电流基，列是入射端口。B 是入射切向场的基函数投影。对于任意近似电流 Y₊、Y₋：

```text
H₊ = B₋ᵀY₊
H₋ = B₊ᵀY₋
V_projection = H₊
V_reciprocal = (H₊ + H₋ᵀ)/2
V_stationary = H₊ + Y₋ᵀ(B₊ − Z₊Y₊)
```

此处 T 表示普通转置，Python 为 `.T`。Galerkin 积分和功率计算的共轭转置则为 `.conj().T`，二者不能混用。若 E₊=X₊−Y₊、E₋=X₋−Y₋，有：

```text
B₋ᵀX₊ − V_stationary = E₋ᵀZ₊E₊
```

右侧是两份电流误差的乘积，因此两组误差同时缩小时输出呈二阶。这是固定离散模型的恒等式，不保证连续物理误差，也不保证筛选保留最优设计。

反射 R₊=−A₊JV₊/N²。A 是谱域电流到切向电场的模态算子，J 将 (m,n) 与 (−m,−n) 配对。互易权重可写为 W₊=−N²JA₊⁻¹。程序使用上述等价矩阵乘法，不额外形成 W。共同参考面上的传输 T=I+R，双面 GSM 为 `[R,I+R; I+R,R]`。

Ex/Ey 不是斜入射下的正交单位功率坐标。功率用传播阶的切向导纳 Gram G 计算。倏逝阶的零实功率不能作为删去其 GSM 接口的理由。

## 预测与电流修正

网络每次预测一个复电流系数的实部和虚部，所有基共用权重。71 维输入包含周期移位后的 64 个掩模像素、两个局部坐标、归一化频率、两个 Floquet 整数阶、入射分量和电流方向。频率归一化为 (f−7)/2，单位 GHz。输出先去除解析入射相位，再用训练集全局电流 RMS 缩放，预测后恢复。

训练使用逐场相对电流 MSE，权重是 `(output_scale / max(field_RMS,1e−6))²`。网络为 71–128–128–2，GELU 激活，80 epochs，128 batches/epoch，batch 4096。AdamW 初始学习率 0.001，余弦衰减到 0.0001，权重衰减 10⁻⁵，梯度总范数上限 5，以验证集误差选择模型。

训练损失不含 PEC 残差。法向入射后续使用预条件 COCG 修正原 EFIE，最高 512 步，真实逐端口相对残差终止阈值 10⁻⁴。各阈值快照在该端口首次经原算子重新检查达标时保存，后续迭代不覆盖早期快照。双线性型失效端口单独记录。

冻结网络没有斜入射输入，因此不会把它声称为斜入射预测器。斜入射的参考电流用真实正反 β 算子计算，驻值提取接受两组近似电流。COCG 只用于法向入射的复对称系统，细网格斜入射参考求解使用 FFT 矩阵自由预条件迭代并检查真实残差。

## 数据与编号

原 900 拓扑集划分为 600 训练、100 验证、200 原测试，固定图示拓扑 701–703 来自该数据集。新 1000 拓扑测试集有独立编号，失败拓扑 954 属于此集合。两个集合不能按编号合并。

HDF5 标签的拓扑是第一维，方便逐例读取。`Labels.case` 接受零基数组索引。转换参考缓存保留原 `info.ids` 的一基编号，以原值核对为准，使用时减 1。Python 新生成的参考结果明确包含 `index_base=0`。

NPZ 中不包含 pickle。`__schema__` 是 JSON，描述数组名、字典、列表或结构体的关系。普通冻结 `model.npz` 则直接包含 W1/b1/W2/b2/W3/b3/N/Q/M/output_scale。

原论文计时来自原始数值实验，格式转换不改变这些记录。当前 Python 计时另存。重新训练使用相同超参数，但随机数和浮点内核不同，不承诺得到逐位相同权重或 COCG 轨迹。
