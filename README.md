# Stationary GSM extraction model and example results

This repository provides the trained current model and numerical solutions for the two examples in *Stationary GSM Extraction from Doubly Periodic Currents Generated by a Learned Model*, by Zhifa Zhang, Shun Lian Chai, and Xiao Ding.

## Contents

- `model/current_model.npz`: the actual shared 71–128–128–2 MLP used for both examples. Its six weight/bias arrays, normalization scale, and N/Q/M metadata are stored as ordinary NumPy arrays.
- `model/definition.json`: architecture, activation, feature ordering, phase restoration, and normalization needed to interpret the model.
- `results/fss/`: five-layer FSS geometry, 500-frequency complex GSM responses, power-response table, five complete layer GSMs at 6.973661202414444 GHz, and solved coupled-stack current coefficients.
- `results/polarizer/`: five-layer linear-to-circular polarizer geometry, 145-frequency complex GSM responses, power/axial-ratio table, five complete layer GSMs at 7 GHz, and solved coupled-stack current coefficients.
- Each example's `definition.json` records array conventions, physical units, references, and accuracy statistics.

The two geometries are the final example designs. All three extraction methods use the same corrected currents at relative EFIE residual 0.1 and the same N = 24, Q = 192, M = 1 interface. Projection, reciprocal averaging, and stationary extraction retain their actual numerical differences.

## Reading the results

NPZ files contain standard arrays and can be opened with NumPy using `numpy.load(path, allow_pickle=False)`. CSV and JSON files can be read directly.

The response matrices have shape (frequency, 4, 4), with ports ordered as front x, front y, rear x, rear y. The blocks are [S11 S12; S21 S22]. `S_coupled` is the full coupled-EFIE reference and `S_matched` is the exact-current M = 1 layer cascade. The other arrays are `S_projection`, `S_reciprocal`, and `S_stationary`.

The FSS response includes all 500 saved frequencies. The polarizer includes 121 fixed base frequencies and 24 local-extremum samples. `base_sample` identifies the 121 frequencies used for its accuracy statistics. Both examples are displayed over 5–9 GHz; the polarizer performance interval is 6–8 GHz.

For front x incidence, the transmitted Jones vector is `S[2:4, 0]`; use column 1 for front y incidence. Total transmittance is the sum of squared component magnitudes. The axial ratio is 20 log10 of the ratio of the two singular values of [Re(E), -Im(E)]. `response.csv` contains these values at full stored precision.

The single-frequency layer GSM files retain all four 18-by-18 blocks of every 36-by-36 matrix. The modal error contribution is 100 times the absolute complex entry difference divided by the reference input-column 2-norm. Rows index outgoing modes and columns index incoming modes.

The current files contain the solved physical stack currents. Coefficients are normalized as eta0 Js for unit incident electric field; divide by the free-space impedance for A/m. The two current components use the rooftop basis on the conducting regions. Masks contain 1 for PEC and 0 for air. Geometry is in metres unless a field name explicitly specifies millimetres.
